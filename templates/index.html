Cómo usar el sistema

1. Proporciona la ubicación para análisis regional preciso

2. Sube una imagen de frutas o usa la cámara

3. Recibe análisis completo con IA específica para Perú

4. Consulta la biblioteca para ver historial

5. Revisa estadísticas en el panel de administración

Consejos para mejores resultados

• Toma fotos con buena iluminación natural

• Enfoca bien las frutas en la imagen

• Usa fondo simple para mejor detección

• Proporciona la ubicación exacta para recomendaciones específicas

• Para frutas verdes, menciona si deseas acelerar la maduración
